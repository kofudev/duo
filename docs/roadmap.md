# Where contributions can help

Duo is an early Windows application. These are areas to explore, not promised delivery dates.

## Reliability first

- More real-account compatibility reports for current Codex and Claude Code releases.
- Better diagnostics when a provider stops, needs login, or returns incomplete usage.
- More realistic local fixtures for cancellation, streaming and review failures.
- Signed Windows releases when a signing identity is available.

## Daily use

- Clearer resume flows for interrupted work and changes awaiting review.
- More accessible keyboard navigation and compact window layouts.
- Better memory import formats and conflict handling without loading entire archives.
- Documentation and translations based on actual setup problems.

## Larger work needing discussion

Connector management, terminal integration, other operating systems and broader provider support need design work before implementation. Exact Claude quota telemetry depends on an official interface becoming available; Duo should not scrape account pages or promise limits it cannot read.

Open an issue with the concrete workflow you need. That helps prioritize changes better than a long list of features.
