# Debugging

Reproduce failure or capture exact evidence first. Establish expected vs actual behavior. Trace inputs through relevant boundaries. Rank plausible causes, then run smallest experiment distinguishing them. Fix demonstrated root cause. Check original reproduction and likely regressions. Avoid broad speculative rewrites. Keep exact error strings. If reproduction impossible, label hypotheses and missing evidence.
