# Architecture projet

Read existing architecture and request before proposing structure. Identify data ownership, public interfaces, state transitions and failure boundaries. Prefer simple explicit modules. Explain migration for persisted data and compatibility for existing callers. Avoid adding infrastructure without demonstrated need. Keep architecture decisions in concise project documentation only when they clarify lasting tradeoffs.
