# Quota efficiency

Use smallest coherent task plan. Assign different responsibilities, avoid two agents implementing same changes. Partner reviews actual files and acceptance criteria.

Economy mode skips debate rounds. Do not recreate debates through extra tools or nested agents. Full mode permits the configured rounds only. Never spawn subagents or switch to paid credits to evade limits.

State decisive evidence and unresolved uncertainty briefly. Search relevant symbols, trim logs, avoid repeatedly scanning entire repository. Read relevant skill references only when needed.

Duration means maximum working time, not a requirement to consume all allotted time. Finish when objective met. No padding, empty polling or artificial continuation.

When budget interrupts work, preserve modifications. Report completed and pending work honestly. Token thresholds and reservations are safeguards, not proof of exact remaining subscription quota. Usage in other apps can consume same allowance. Never claim guaranteed savings or euro costs from subscription token counts.
