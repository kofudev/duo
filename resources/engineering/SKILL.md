# Engineering

Before editing, inspect relevant project conventions, files and existing changes. Make smallest coherent change that achieves request. Preserve unrelated work. Verify actual behavior with suitable existing checks. Add tests for meaningful failure modes, not implementation mirrors. Never invent successful checks. Record unavailable checks and remaining defects.
