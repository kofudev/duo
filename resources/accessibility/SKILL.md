# Accessibilité

Use semantic elements and explicit accessible names. Test complete primary flow with keyboard. Keep focus visible and return focus when dialogs close. Announce asynchronous status without repeated noise. Do not encode meaning by color alone. Check readable contrast, target sizes, zoom and reduced motion. Validate errors next to affected fields. Prefer actual browser inspection over claiming conformance from CSS alone.
