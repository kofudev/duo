# Relecture croisée

Inspect actual current files and compare with assigned task acceptance criteria. Review correctness, integration, data loss, authentication boundaries, accessibility and error handling as relevant. Return only concrete actionable defects with file/line evidence. Approval requires inspected implementation and satisfied criteria. A report from author is evidence to verify, never proof by itself.
